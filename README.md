# CogniAgents Framework

Welcome to the CogniAgents Framework! This project provides a flexible and extensible way to define, orchestrate, and execute AI agents and workflows using simple YAML configurations.

## Features

*   **Configuration-driven**: Define agents, workflows, and templates entirely through YAML files.
*   **Modular Agents**: Easily integrate different LLM models and define agent behaviors with prompts and output schemas.
*   **Workflow Orchestration**: Chain agents together in sequential or parallel steps to build complex AI pipelines.
*   **Structured Output**: Leverage Pydantic schemas for agents to ensure structured and validated outputs.
*   **Templating**: Use Jinja2 for dynamic rendering of workflow results into human-readable formats.
*   **Extensible**: Designed for easy addition of new agent types, output schemas, and workflow steps.
