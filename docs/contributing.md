# Contributing

Contributions are welcome! We appreciate your help in making CogniAgents better.

## Bug Reports & Feature Requests

If you encounter a bug or have an idea for a new feature, please open an issue on our [GitHub repository](https://github.com/your-username/CogniAgents/issues).

Please provide as much detail as possible:
- For bugs: Steps to reproduce, expected behavior, actual behavior, and your environment.
- For features: A clear description of the new functionality and its use case.

## Development Process

1.  **Fork** the repository on GitHub.
2.  **Clone** your fork locally: `git clone https://github.com/your-username/CogniAgents.git`
3.  **Create a new branch** for your changes: `git checkout -b feature/my-new-feature` or `fix/a-specific-bug`.
4.  **Make your changes.** Ensure you add or update docstrings and tests where appropriate.
5.  **Run tests** to ensure everything is working correctly: `pytest`.
6.  **Commit** your changes with a descriptive commit message.
7.  **Push** your branch to your fork: `git push origin feature/my-new-feature`.
8.  **Open a Pull Request** from your fork to the main CogniAgents repository.
